# Store listing images

Generated by `direnv exec . node scripts/store-assets.mjs` (builds first: `direnv exec . npm run build`). The compositions in `pages/` run the
**real** popup / picker / settings bundles from `dist/chrome-mv3` against sample data (`stub.tpl.js`), so the screenshots are the actual UI.
Outputs land in `out/` (committed).

| File | Size | Use |
|---|---|---|
| `01-hero.png` … `05-settings.png`, `06-features.png` | 1280×800, 24-bit PNG (no alpha) | Chrome Web Store screenshots (up to 5; use 01–05 or swap in 06) · Firefox AMO screenshots (1280×800 is the recommended size; AMO accepts more) |
| `promo-small.png` | 440×280 | Chrome Web Store **small promo tile** (required) |
| `promo-marquee.png` | 1400×560 | Chrome Web Store **marquee** (optional, needed to be featured) |
| `social.png` | 1200×630 | Link-preview / social card |
| `icon-128.png` | 128×128 (96×96 art + 16 px transparent padding) | Chrome store icon (also in the extension zip as `icons/128.png`) |
| `icon-64.png` | 64×64 | Firefox AMO listing icon (AMO uses 32/64 px) |

Requirements checked: Chrome Web Store — screenshots 1280×800 or 640×400, small tile 440×280, marquee 1400×560, icon 128×128 with
16 px padding (https://developer.chrome.com/docs/webstore/images). Firefox AMO — screenshots recommended at 1280×800 (1.6:1), icons
32/64 px (https://extensionworkshop.com/documentation/develop/create-an-appealing-listing/).

The sample sites are a fictional mail app ("Postbox") and GitHub (used only to show a real service in the popup/picker/settings).
